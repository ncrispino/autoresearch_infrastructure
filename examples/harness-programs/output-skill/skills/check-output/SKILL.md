name: check-output
description: Check the requested output artifact before completing a file-producing task.
---

Read the output requirements in the public task instruction. Before finishing:

1. Confirm the output exists at the requested path.
2. Reopen it with an available task tool and check its format and required content.
3. Report a check you could not perform. Never invent a successful check.

Use only the capabilities granted to this session. This skill adds guidance, not tools.
